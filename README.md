> Один и тот же инструмент могут использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов помещает файлы WinDivert в категории инструментов повышенного риска или хакерских средств. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить папку в исключения. При недостаточном понимании настроек рекомендуется отключить детектирование PUA.

## ⚙️Как начать работу

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите параметр "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> нужную стратегию.

## ℹ️Назначение файлов и пунктов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — включить или отключить обход для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Этот пункт полезен при диагностике ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается один из режимов:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — адрес проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP-адрес
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — получить из репозитория актуальную версию `ipset-all.txt`
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

При запуске стратегии отдельным BAT-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированные строки в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Cloudgleimagine/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Отдельный вариант способен работать некоторое время, а затем перестать работать после обнаружения.
> Здесь собрано много разных стратегий. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте сообщения в `service.bat` -> `Run Diagnostics`.

- Удостоверьтесь, что нужный адрес указан в списке доменов или IP-адресов.

- Испытайте другие варианты, в том числе **`ALT`**, **`FAKE`** и прочие.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок устраните их, затем в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, включите его, нажмите применить и подтвердите кнопкой ОК.
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, включите его автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в службах

1. Получите имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив имя из первого шага:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fкак-начать-работу).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Испытайте остальные стратегии, особенно если прежняя раньше работала.
- См. также [#251](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fкак-начать-работу) настроен.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- После очистки проверьте приложение Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если сайт также не открывается, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Cloudgleimagine/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит сделать следующее:
- обновить ipset через `service.bat` и включить `Game Filter`;
- если это не помогло, дополнительно включить `ipset any`.

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Списки для обхода можно дополнить следующими файлами:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например если сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
